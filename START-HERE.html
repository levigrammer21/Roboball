FOOTBALL STRATEGY · 1.0.0

Get your field ready.

Your Firebase configuration is already integrated. Complete these console steps, then invite a friend.

1. Enable sign-in

In Firebase Console, open footballstratagy → Authentication → Sign-in method. Enable Email/Password. Under Settings → Authorized domains, add YOUR-USERNAME.github.io.

2. Publish the rules

Open Firestore Database. Create the default database in production mode if needed. In the Rules tab, paste all of firestore.rules and tap Publish. No collections or composite indexes need manual creation.

3. Upload the files

Unzip the download. Upload all files inside its project folder to your GitHub repository root. The root must contain index.html. Open Settings → Pages → Deploy from a branch → your branch → /(root).

4. Play a friend

Open the GitHub Pages URL. Tap the account icon, create your account and set a coach name and color. Create a room and share the code. Your friend signs into their own account and joins. Both coaches program and lock three turns, then watch the replay.

Console setup and live two-account play have not been verified for you. Complete the live checks in SETUP.md. Practice needs no sign-in.
